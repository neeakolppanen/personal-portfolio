# Personal Portfolio Website
## Vaatimusmäärittely (Requirements Specification)

**Versio:** 0.2  
**Projektin tyyppi:** Henkilökohtainen portfolio  
**Tila:** Suunnitteluvaihe  
**Frontend:** React, TypeScript ja Vite

---

## 1. Projektin kuvaus

Projektin tavoitteena on suunnitella ja toteuttaa moderni, visuaalisesti näyttävä henkilökohtainen portfolioverkkosivusto.

Sivuston tarkoituksena on esitellä henkilön ammatillista taustaa, teknistä osaamista, projekteja sekä UX/UI-suunnitteluun liittyvää osaamista.

Projektissa yhdistyvät käyttöliittymäsuunnittelu ja moderni frontend-kehitys.

## 2. Kohderyhmä

Sivuston ensisijaisia käyttäjiä ovat:

- IT-alan rekrytoijat ja työnantajat
- Ohjelmistokehitysyritykset
- Mahdolliset asiakkaat ja yhteistyökumppanit
- Muut teknologia-alan ammattilaiset

## 3. Projektin tavoitteet

1. Rakentaa ammattimainen ja persoonallinen verkkosivusto.
2. Esitellä frontend-kehityksen osaamista Reactin ja TypeScriptin avulla.
3. Tuoda esille UX/UI-suunnittelun osaamista.
4. Esitellä omia ohjelmistoprojekteja ja suunnittelukonsepteja.
5. Luoda visuaalisesti kiinnostava ja helppokäyttöinen käyttökokemus.
6. Harjoitella oikean ohjelmistoprojektin suunnittelu-, kehitys- ja julkaisuprosessia.

## 5. Ei-toiminnalliset vaatimukset (Non-Functional Requirements)

- Sivuston tulee olla responsiivinen.
- Käyttöliittymän tulee olla visuaalisesti yhtenäinen.
- Sivuston tulee olla saavutettava ja helposti navigoitava.
- Animaatiot eivät saa merkittävästi heikentää suorituskykyä.
- Sivuston tulee tukea käyttäjän vähennetyn liikkeen asetusta (prefers-reduced-motion).
- Koodin tulee olla ylläpidettävää ja komponenttipohjaista.
- Projektissa käytetään TypeScriptiä.
- Sivuston latausnopeuteen ja suorituskykyyn tulee kiinnittää huomiota.

## 6. Visuaaliset vaatimukset (Design Requirements)

**Visuaalinen suunta:** Dark Luxury.

Suunnitteluperiaatteet:
- Tumma ja elegantti värimaailma.
- Harkittu typografia ja selkeä visuaalinen hierarkia.
- Suuret otsikot ja persoonalliset asettelut.
- Hienostuneet yksityiskohdat ja korostusvärit.
- Edistyneet animaatiot ja scroll-efektit.
- Interaktiiviset käyttöliittymäelementit.
- Selkeä ja johdonmukainen käyttökokemus.

## 7. Sivuston kieli

Sivuston ensisijainen ja tässä projektiversiossa käytettävä kieli on suomi.

## 8. Teknologiset vaatimukset (Technical Requirements)

- React
- TypeScript
- Vite
- CSS
- Git ja GitHub
- Figma käyttöliittymäsuunnitteluun
- Netlify julkaisuympäristönä

## 9. Projektin laajuus (Project Scope)

Ensimmäinen versio keskittyy frontend-toteutukseen.

Sivusto sisältää:
- Etusivun
- Henkilökohtaisen esittelyn
- Osaamisen esittelyn
- Projektien esittelyn
- Projektien yksityiskohtaiset esittelyt
- Yhteystiedot

Projektisisältö koostuu toteutetuista omista projekteista sekä kuvitteellisista UX/UI-konsepteista.

Backend- ja tietokantaintegraatiot eivät kuulu ensimmäiseen versioon.

Arkkitehtuurin tulee mahdollistaa sivuston laajentaminen myöhemmin.

## 10. Hyväksymiskriteerit (Acceptance Criteria)

Projekti voidaan hyväksyä valmiiksi, kun:

- Kaikki suunnitellut osiot on toteutettu.
- Navigointi toimii oikein.
- Projektien tiedot näkyvät oikein.
- Sivusto toimii eri näyttökoilla.
- Animaatiot ja vuorovaikutteiset elementit toimivat oikein.
- Saavutettavuus ja suorituskyky on tarkistettu.
- Sivusto on julkaistu ja käytettävissä verkossa.
